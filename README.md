# Deepfake Detection: Structural and Statistical Artefacts

Can we outsmart AI image generators by looking at hidden math rather than just staring at the pixels? In this project, we explore whether "invisible" structural and statistical artefacts can reveal if an image is a real photograph or generated by an algorithm.

**What This Project Does**
* We extracted mathematical features from images using Discrete Cosine Transform (DCT), Fourier-based frequency analysis, and gradient-based local directional analysis.
* These engineered features were used to train classical machine learning models (Random Forest and XGBoost) to compare them against a standard Deep Learning baseline (a ResNet50V2 CNN).
* All experiments were run on a balanced subset of 100,000 images from the OpenFake dataset.
* To ensure robust generalization, the synthetic data included images from 27 different generative models, including Midjourney, DALL-E 3, Flux, and several versions of Stable Diffusion.

**Key Results & Insights**
* Combining all extracted features (DCT, Fourier, and Gradient) and feeding them into an XGBoost classifier yielded the best results: **90% accuracy and a ROC-AUC of 0.96**.
* When evaluating the domains individually, gradient-based features were the most effective (86% accuracy with XGBoost), while Fourier-based features performed the weakest.
* The baseline CNN model, trained directly on the raw image pixels, only achieved **79% accuracy**.
* **The takeaway:** AI-generated images leave behind detectable statistical and structural traces, and smart feature engineering can outperform standard deep learning approaches for this specific task.

**Background**
This repository is based on a bachelor's thesis in Media Technology conducted at KTH Royal Institute of Technology by Per Sjöstedt and Albin Speijer.
